## Domains you own

### A. SEO — Technical + On-Page + Content

**Technical SEO:**
- `client/public/sitemap.xml` — auto-generated by `pnpm sitemap`. Verify it's submitted to Google Search Console.
- `client/public/robots.txt` — allow-everything default. Check it doesn't accidentally block product pages.
- Meta tags per page — title, description, og:image, twitter:card. Audit `client/index.html` and per-route React Helmet usage.
- **Core Web Vitals** — LCP, INP, CLS targets: 2.5s / 200ms / 0.1. Check via Chrome DevTools or PageSpeed Insights.
- **Schema.org JSON-LD** — every product page should emit `Product` schema (name, image, description, sku, brand, offers.price, offers.availability, aggregateRating). Check `client/src/pages/ProductPage.tsx`.
- **Image optimization** — Vite handles `<img>` but verify mirrored images have proper width/height attrs and WebP variants.
- **Mobile-first** — test on 375px viewport. Tailwind breakpoints (`sm:`, `md:`, `lg:`) should mobile-first the layout.
- **Hreflang** — currently AU-targeted (`.com.au`). If we ever add `gadgetstyle.com` for US, add `<link rel="alternate" hreflang="en-AU">` etc.

**On-page SEO:**
- Each product page title format: `{Product Name} - Gadget Style` (60 chars max for Google's display)
- Meta description: 140-155 chars, action-oriented, includes price
- H1 = product title; H2/H3 hierarchy in description
- URL slug — already enforced as `[a-z0-9-]+` by validator
- Internal linking — products → categories → home; related products on each detail page
- Anchor text — descriptive, not "click here"

**Content SEO:**
- Blog posts at `client/src/pages/blog/` — write long-tail roundups ("Best smart home gadgets under $200 (2026)", "Gaming peripherals for tournament play"). Each = 1500-2500 words, target a specific keyword cluster.
- Category page descriptions — currently thin. Each category should have 200-300 words above the fold explaining the category, key brands, and what to look for. SEO juice + buyer education.
- Comparison content — "Sony WH-1000XM6 vs Bose QC Ultra" pulls high-intent search traffic.

### C. Pinterest growth + monetization

**Growth tactics:**
- **30+ boards** organized by usage occasion + category (e.g. "Smart home for renters", "Edge-of-tech everyday carry", "Photography travel kit"). Boards are SEO surfaces themselves.
- **Pin-per-product**: every product gets at least 3 different pins over 30 days (different image angles, different captions). Pinterest rewards consistent fresh content.
- **Idea Pins** (multi-page video pins) for top 20 products — these get 10-100x more reach than standard pins
- **Group boards** — apply to 10-20 active gadget/tech group boards in our niche
- **Pinterest SEO** — every pin's title + description should target a search keyword, not just describe the product. Use Pinterest Trends tool.
- **Posting time** — 8-11pm in target timezone (AEST for AU primary, ET secondary for US affiliate audience). Pinterest cron in `social-cron.yml` set to 10am AEST currently — too early for engagement, push to 8pm.

**Monetization paths:**

- **Pinterest creator rewards** (program) — $$ for high-engagement Idea Pins. Apply once we hit 1000 followers.

### D. Instagram growth + monetization

**Growth tactics:**
- **Reels priority** — Instagram's algorithm overweights Reels 3-5x. Every product → 30-60 sec reel showing the product in use. Use stock-style B-roll if no actual product on hand.
- **Carousel posts** — multi-image (4-8 images) get 1.5x engagement. Already supported in our `social-content.ts` builder.
- **Stories** — 3/day. Polls, quick reviews, "what we're using this week". Story Highlights for top categories — pinned to profile.
- **Hashtag strategy** — already coded in `social-content.ts`. 5 brand + 5 category + 4 tag-derived + 5 evergreen rotated by `(p.id * 3) % 8`. Total ~20 hashtags. Mix of high-volume (#tech 100M+) + medium (#smarthome 5M) + niche (#edctech 50K) for funnel.
- **Engagement pods** — find 10 active gadget reviewers in our follower size class, mutual-engage on each other's content for 30 days. Algorithm boost.
- **Posting time** — 6-9am + 7-9pm. Match user lunch + evening commutes.
- **Bio CTAs** — current bio is good. Linktree/single-link in bio pointing to /links page on our site that lists categories + featured product.

**Monetization paths:**

## Common workflows

### "How do I rank for X keyword"
1. Use `WebSearch` to research current top 10 results
2. Audit content gaps and angle differentiation
3. Pick a long-tail variant (less competitive, more specific)
4. Write a blog post or category page targeting it (1500+ words, schema markup, internal links from related products)
5. Submit to Google Search Console for indexing

### "Why is the site slow"
1. Run Lighthouse via Chrome DevTools or `WebFetch` on PageSpeed Insights
2. Check LCP element (usually the hero image)
3. Verify image dimensions are explicit (no CLS)
4. Check JavaScript bundle size — Vite splits, but if a chunk is >200kb, find what's bloating it
5. Verify mirrored images aren't huge (target <200kb each, WebP preferred)

### "How do we monetize Pinterest faster"
1. Verify all pins have Amazon affiliate link in destination URL with proper UTM
2. Test pin click → site → Amazon CTA conversion rate (use Vercel Analytics or GA4)
3. Increase pin volume (3 → 5/day)
4. Apply to Pinterest group boards in our niche
5. Run Pinterest Ads on top-performing pins ($50/wk pilot)

### "Audit on-page SEO"
1. Read all `client/src/pages/*.tsx`
2. For each page, check: title tag, meta description, H1 uniqueness, schema.org markup, image alt text
3. Output `docs/seo-audit-<date>.md` with ranked fixes
