# Social Setup — Remaining User Tasks

Everything that was safe and efficient to do autonomously is done. What's left
is a tight sequence of ~15 minutes of hands-on work that must be done by you
because of hard security/privacy gates (CAPTCHA, SMS verification, profile
photo upload, credit-card-less account verification). Nothing below requires
any code changes on your end.

**Do these in order** — later steps depend on earlier ones.

2. **Scroll down** to the reCAPTCHA and click **"I'm not a robot"**. Solve any image puzzle.
3. Click **Submit**. You'll land back on **My apps**.
4. Click the newly created **Gadget Style Social** app.
5. Copy the **App ID** and **App secret key** from the Credentials section.
6. Under **Redirect URIs**, add: `http://127.0.0.1:47501/callback` (this is what the OAuth setup script will use). Keep the production URI too if one exists.
7. Paste into `.env.local` at the repo root (create it if missing):

   ```
   PINTEREST_CLIENT_ID=<paste app id>
   PINTEREST_CLIENT_SECRET=<paste app secret>
   ```


## 8. Exchange OAuth codes for refresh tokens (~2 min, automated)

Everything above was setup. This step is the automation handoff.

Open a terminal in the repo root:

```bash
pnpm social:oauth pinterest
# Browser will open → click "Give access" → tokens saved automatically

pnpm social:oauth meta
# Browser will open → click "Continue as [your name]" → tokens saved automatically
```

Each script:
1. Opens your browser to the platform's authorize URL
2. Runs a local server at `127.0.0.1:47501/callback` to catch the redirect
3. Exchanges the returned code for a long-lived refresh/page token
4. Writes the token to `.env.local`
5. Closes itself

If the Meta script errors with "No Pages found" or "no IG linked", retry step 5 above and make sure the Page is active + linked.

## 9. Test a single post (~1 min)

Pick any live product and try posting to both platforms in dry-run first:

```bash
pnpm social:post --id 100 --dry-run
```

If the content preview looks right, do a real post:

```bash
pnpm social:post --id 100
```

Verify the pin appears in your Pinterest and the post in your Instagram feed.

## 10. Wire the daily cron (~3 min)

1. Push your repo to `main` on GitHub (the workflow at `.github/workflows/social-cron.yml` is already committed).
2. Go to your GitHub repo → **Settings → Secrets and variables → Actions → New repository secret**, and add each of:
   - `PINTEREST_CLIENT_ID`
   - `PINTEREST_CLIENT_SECRET`
   - `PINTEREST_REFRESH_TOKEN`
   - `META_APP_ID`
   - `META_APP_SECRET`
   - `META_PAGE_ACCESS_TOKEN`
   - `META_IG_BUSINESS_ID`
3. Go to **Actions → Social queue (daily) → Run workflow** → check "Dry run" and run. Confirm the preview looks right.
4. Uncheck dry run next time — the cron is now live daily at **10:00 AEST**.

Adjust the cron expression in `social-cron.yml` if you want a different posting time.

## Token lifetimes (set a calendar reminder)

- **Pinterest refresh token:** 1 year. When it expires, run `pnpm social:oauth pinterest` again.
- **Meta Page token:** ~60 days. Run `pnpm social:oauth meta` every 50 days to refresh. You could also add this to a cron that fails loudly when the token expires, but monthly manual refresh is simpler.

## If something breaks

Common failure modes and fixes:

| Symptom | Likely cause | Fix |
|---------|--------------|-----|
| "No boards found" | Pinterest account has no boards yet | Create at least one board at pinterest.com |
| "None of your Pages have IG linked" | IG not converted to Business/Creator, or not linked to FB Page | IG app → Settings → Account → Switch to Professional → Link to Page |
| Pinterest CSP blocks the callback | Wrong redirect URI | Match `http://127.0.0.1:47501/callback` exactly in app settings |
| "image URL not accessible" | Site not yet deployed or image 404s | Deploy to Vercel first; Pinterest/Meta fetch the image server-side |
| Meta publish fails with "Rate limited" | IG limits ~50 posts/day | Wait 24h or cut down the daily count |
| "session expired" on Meta | Page token expired | Re-run `pnpm social:oauth meta` |
